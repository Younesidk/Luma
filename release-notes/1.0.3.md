## Luma 1.0.3

- Luma now fits smaller and scaled screens: the window sizes itself to your display, so the close button and version are always visible
- On narrow windows the sidebar collapses to icons automatically, and the featured banner and filters panel shrink to fit
- Smoother scrolling with the mouse wheel, and no more stutter while resizing the window or collapsing the sidebar
- GPU rendering is now the default for smoother animation (switch back under Settings → Performance → Graphics if you prefer lower memory use)

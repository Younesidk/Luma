## Luma 2.0

### A new look and feel, built on Windows' own UI

- Luma has been rebuilt on WinUI 3, the same modern UI that Windows 11 apps use. It looks the same as before, but feels more at home on Windows
- Smoother scrolling, crisp text and icons at every display scale (100%, 125%, 150% and up)
- Buttons and sidebar items fade softly when you hover over them, and keyboard focus is easier to see
- In the preview, small wallpapers are now shown sharp at their real size instead of being stretched

### Under the hood

- Thumbnails and previews are decoded by Windows itself and use memory more carefully while you scroll
- WebP and GIF wallpapers are converted for Windows without any extra libraries
- Your library, favourites, collections, settings and live wallpaper carry over untouched

Luma 2.0 needs Windows 10 (version 2004 or later) or Windows 11.
